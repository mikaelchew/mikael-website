# Mikael Chew Website

> Personal brand and book-launch site for Mikael Chew at mikaelchew.com.

## What this is

Static HTML/CSS/JS site serving as Mikael Chew's personal brand hub for his Zinzino business and thought-leadership content. It is live at mikaelchew.com. The site is currently running a 12-week book-launch campaign for 《直銷孫子兵法之不戰而勝》 ("The Art of War for Direct Selling"), with a target launch window of July–August 2026.

## Tech stack

- Static HTML pages (no framework)
- Custom CSS in `css/`
- Vanilla JS in `js/`
- `build_zh.py` — Python script that generates the Chinese (`zh/`) version of pages
- `server.py` — local dev server for previewing the site
- CNAME set to `mikaelchew.com`

## Setup

```bash
# No install step required — pure static site
# Run local preview server:
python3 server.py
```

## Run / Build / Test

```bash
python3 server.py          # local dev server
python3 build_zh.py        # regenerate zh/ Chinese pages from source
```

## Campaign phase structure

The book launch is a 12-week campaign in three phases:

### Phase 1 — Pre-Launch (Weeks 1–6)
- Weeks 1–2: Foundation — finalize manuscript, set up book sales page, pre-order mechanism, email list landing page, visual assets
- Weeks 3–4: Teaser Campaign — announce launch date, "Behind the Book" content series, excerpt posts, endorser and podcast outreach
- Weeks 5–6: Momentum Building — ramp content to 3–4 posts/week, share endorsements, release Chapter 1 preview more aggressively, form a 20–30 person Book Launch Team, send advance review copies

### Phase 2 — Launch Week (Week 7)
- Day 1: Full multi-channel announcement, email blast, launch video, activate Book Launch Team, update book.html with live purchase links
- Days 2–3: Share first reader reactions, run "First 100 buyers" or launch-week special
- Days 4–5: Chapter insight teaser, live Q&A, YouTube/podcast episode
- Days 6–7: Final urgency push, review roundup, community thank-you

### Phase 3 — Post-Launch (Weeks 8–12)
- Weekly book insight posts, reader review collection, podcast guest appearances, blog posts tied to book concepts
- Secondary pushes: Week 9 reviews compilation, Week 11 "missed launch week" reminder, Week 12 announce what's next (coaching, masterclass, speaking)

## Conventions & gotchas

- The site has both English pages at root and a Chinese mirror under `zh/` — always run `build_zh.py` after editing any page that has a Chinese equivalent
- `book.html` is the critical page to keep updated throughout the campaign; it starts as "Coming Soon" and goes live on launch day
- Distribution is primarily via mikaelchew.com direct sales (highest margin, captures customer data); secondary channels are Amazon, Malaysian bookstores (MPH, Kinokuniya, Popular), bulk orders, and speaking events
- Pricing: Physical RM 79–99, Digital/eBook RM 39–49
- Book is in Traditional Chinese; English translation is a post-launch consideration
- All campaign tracking checklists live in `BOOK_LAUNCH_PLAN.md` — update checkboxes there as tasks complete
